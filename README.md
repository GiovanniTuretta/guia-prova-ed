# Guia de prova: Estruturas de Dados em C

Guia de estudo em uma página só: teoria explicada do zero, treino estilo Duolingo, laboratório com os algoritmos rodando passo a passo, simulado e vídeos recomendados.

Acesse: https://giovannituretta.github.io/guia-prova-ed/

Assuntos: Big O, Bubble/Selection/Insertion/Quick/Merge Sort, ponteiros, malloc/realloc/free, struct, busca sequencial e binária, tabela hash.
